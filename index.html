Architecture as implemented

backs Sec. II-A to II-D

A shared four-layer convolutional stem encodes every frame independently to a 256-channel feature map. Each frame is refined by the Multi-Scale SAM block, then the refined frames are mean-pooled over time before the capsule stage. Temporal information therefore enters through per-frame modulation, not through a sequence model after pooling.

Multi-Scale SAM block, applied per frame in this fixed order
StepStageMechanismApplied as
1Channel CBAM-style squeeze-excitation. Average and max pooling share one bottleneck MLP at reduction ratio 8, summed, sigmoid. multiplicative
2Temporal motion map Frame t concatenated with frame t-1, two parallel convolutions at 3×3 and 5×5, fused by 1×1 and sigmoid. map only
3Spatial Point prompt added to the channel-refined features, concatenated with the motion map, then 1×1 / 3×3 / 1×1 ending in a sigmoid. multiplicative
4Temporal residual out + tanh(alpha) · (out · a_m). The gate is signed, so motion regions can be amplified rather than only suppressed. additive residual

Frame 0 has no predecessor, so it receives no motion map and skips steps 2 and 4. The point prompt is a learned per-channel bias initialised at sigma = 0.1, and it is applied only when the spatial branch is active.

The capsule stage is the standard two-layer arrangement. PrimaryCaps is a 3×3 convolution reshaped into 8-dimensional capsules and squashed. ActivityCaps runs three dynamic-routing iterations to one 16-dimensional capsule per class. The class decision is the L2 norm of the output capsules, trained with cross-entropy over those norms rather than the original margin loss.

The routing tensor W is shaped (in_caps, num_classes, 16, 8), so its size scales with the product of the input-capsule count and the class count. Training protocol

Cell 6, Sec. II-F

Fixed across every configuration and both datasets. No early stopping, no per-configuration tuning. The checkpoint with the best validation accuracy is the one evaluated on test.

Reproducing the results

Requires a CUDA GPU with at least 8 GB, PyTorch, and a local copy of UCF-101. The first pass over the data decodes video and is slow; later passes load from the on-disk frame cache.

  • Run Cells 1 to 6B to define the dataset, model, ablation registry and training utilities.
  • Set DATASET_PATH in Cell 7A. Cell 8A is a path diagnostic that reports what it can and cannot find before you commit to a long run.
  • Run Cell 8 to build the frame cache, then Cell 9 as a single-seed smoke test.
  • Run Cell 10, then Cell 10B, then Cell 10C for Table 1.
  • For the 101-class row, switch to Cell 7B, re-run Cell 8 with CLASS_SUBSET = None, then run Cell 9B.

UCF-101 is distributed by its original authors at crcv.ucf.edu/data/UCF101.php, and the UCF-11 YouTube Action set at crcv.ucf.edu/data/UCF_YouTube_Action.php. The subject-independent splitter in Cell 10A reads group identifiers from either the filename or the parent folder, so it works with either distribution layout.
